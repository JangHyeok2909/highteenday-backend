답해 보는 날짜를 관리한다.

## 올리는 규칙

- B·C 등급 작업을 마치면 한 줄 추가한다. A는 올리지 않는다.
- 새 줄의 단계는 0이고, 다음 복습은 다음 날이다.
- C 항목은 단계 3 이상(7일 간격 복습 통과)이 된 뒤에 이력서와 면접 카드에 올린다.

## 단계와 간격

| 단계 | 다음 복습까지 |
|---|---|
| 0 | 1일 |
| 1 | 3일 |
| 2 | 7일 |
| 3 | 21일 |
| 4 | 60일 |

통과하면 단계를 하나 올리고, 부분이면 그대로 두고, 실패하면 0으로 내린다.
단계 4에서 통과하면 `졸업`으로 표시하고 더 묻지 않는다.

- **통과**: 결론과 근거, 버린 대안을 댔다
- **부분**: 결론은 맞지만 근거나 대안이 비었다
- **실패**: 결론이 틀렸거나 답하지 못했다
