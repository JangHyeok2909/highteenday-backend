# 자료구조·알고리즘 개념

판정 기준과 칸 설명은 [README](README.md)에 있다.

면접에서 말로 묻는 개념이다. 풀이 연습은 코테 준비가 따로 맡는다.

이 분야는 원래 프로젝트 사례가 잘 안 붙는다. 사례가 있는 것은 Redis 내부 구조(DS-14)와 인덱스
구조(DS-18)뿐이다. 둘 다 "그 자료구조를 왜 거기 쓰나"로 이어 묻기 좋은 질문이다.

나머지는 B면 충분하고 C만 없애면 된다.
