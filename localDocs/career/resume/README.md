## 빌드

```bash
cd localDocs/career/resume
node build.js                                  # resume.md → out/resume.pdf
node build.js resume.md    resume-daangn       # 원본과 출력 이름을 따로 지정
node build.js portfolio.md portfolio-daangn
```

의존성이 없다. `npm install` 불필요하고 pandoc·wkhtmltopdf 도 필요 없다.
마크다운 변환기는 `build.js` 가 직접 갖고 있고, PDF 는 Chrome 헤드리스가 만든다.

Chrome 경로는 `C:\Program Files\Google\Chrome\Application\chrome.exe` 를 기본으로 찾는다.
다른 곳에 있으면 `CHROME_PATH` 환경변수로 지정한다.

빌드가 끝나면 **덜 채운 자리가 몇 개 남았는지** 콘솔에 나온다. 제출 전에는 0이어야 한다.

## 원고를 쓰는 두 가지 약속

### 1. `[[...]]` — 아직 안 채운 자리

```markdown
[[이메일]] · [[전화번호]]
```

PDF 에서 **빨간 점선 상자**로 찍힌다. 일부러 눈에 거슬리게 만들었다 —
덜 채운 채로 제출하는 사고를 막기 위해서다. 빌드 로그에도 목록이 나온다.

### 2. `<!-- CUT -->` — 여기부터는 PDF 에 안 들어간다

원고 아래쪽에 이 마커가 있고, 그 밑은 **초안 메모 구역**이다.
아직 확정되지 않은 문장, 구현이 끝나면 올릴 줄, 버린 문장을 여기에 둔다.
지우지 않고 남겨 두어도 PDF 는 깨끗하게 나온다.

## 쓸 수 있는 마크다운 문법

이력서에 필요한 것만 지원한다.

| 문법 | 결과 |
|---|---|
| `# ## ### ####` | 제목 4단계 (`#` 이름 / `##` 대분류 / `###` 회사·프로젝트 / `####` 항목 제목) |
| `- 항목` | 목록. 두 칸 들여쓰면 한 단계 안으로 |
| `**굵게**` `*기울임*` `` `코드` `` | 글자 서식 |
| `[글자](주소)` | 링크 |
| `> 인용` | 인용 블록 |
| `---` | 구분선 |
| `\| 표 \|` | 표 (머리줄 + `\|---\|` 구분줄 필요) |
| ` ```코드 ` | 코드 블록 |
| ` ```html-raw ` | **HTML 을 그대로 통과시킨다.** 그림과 장 나눔에 쓴다 |

지원하지 않는 것: 이미지, 각주, 체크박스, 중첩 인용.
**필요하면 `build.js` 에 추가한다** — 변환기가 이 파일 안에 있으니 고치기 쉽다.

### `html-raw` 로 쓸 수 있는 것

`template.html` 에 미리 넣어 둔 클래스들이다. 포트폴리오에서만 쓴다.

| 쓰임 | 클래스 |
|---|---|
| 장 나눔(다음 쪽에서 시작) | `<div class="pagebreak"></div>` |
| 막대 그래프 | `.bar-row` > `.bar-label` · `.bar-track` > `.bar-fill` · `.bar-val` |
| 흐름도 | `.flow` > `.flow-step` · `.flow-arrow` |
| 좌우 대비 상자 | `.compare` > `div` > `h5` |
| 그림 설명 | `.fig` 로 감싸고 `.fig-cap` |
| 목차 | `.toc` > `div` > `.num` |
