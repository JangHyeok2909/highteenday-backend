# 모범 원고

포트폴리오와 이력서를 다시 쓸 때 뼈대로 삼는 원고 하나를 둔다. 2026-09-06에 골랐다.

| 파일 | 무엇 |
|---|---|
| [jaenyeong-about.md](jaenyeong-about.md) | 김재녕의 이력서 원문. https://jaenyeong.github.io/about/ 을 2026-09-06에 그대로 복사했다 |
| [skeleton.md](skeleton.md) | 그 원고에서 잰 구조. 항목 하나의 자리, 분량, 수치가 놓이는 곳 |

원문은 고치지 않는다. 개인 참고용 사본이고 밖으로 내보내지 않는다.

## 왜 이것인가

- Java·Kotlin, Spring Boot, JPA, AWS. 우리 스택과 같다.
- 트러블슈팅 하나가 두 줄이다. 첫 줄이 증상과 결과, 둘째 줄이 원인.
- 7년 경력이 공백 제외 **8,112자**다. 그림 0, 표 0, 상호참조 0, 교훈 문장 0.
- 글쓴이가 [개발자 이력서 작성 가이드](https://jaenyeong.github.io/resume/guide/)의 저자다. 원고와 가이드가 같은 사람 것이라 어긋나지 않는다.
