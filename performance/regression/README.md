# Regression

회귀 판정은 현재 실행을 조건이 같은 과거 실행과 비교한다. 가장 최근 실행이라는 이유만으로
기준선이 되지는 않는다.

## 기준선 선택

다음 조건이 일치하고 측정이 완전한 과거 실행 중 가장 최근 것을 선택한다.

- 시나리오와 실행 환경
- 데이터셋과 상태 지문
- 부하 프로필과 판정 구간
- 부하 발생기 위치
- 필요한 지표 존재 여부

조건이 맞는 실행이 없으면 상대 비교를 생략한다. 느린 실행도 측정이 유효하면 기준선이 될 수
있다. 기준선은 성능 합격본이 아니라 변화 비교의 출발점이다.

## 판정

규칙은 [rules.json](rules.json)에 있다.

- `PASS`: 회귀 임계와 절대 한계를 넘지 않음
- `WARN`: 확인이 필요한 변화가 있음
- `FAIL`: gate 지표가 실패 조건을 넘음
- `UNMEASURED`: 필수 지표가 없어 판정할 수 없음

상대 변화율은 `noiseFloor`보다 작은 절대 변화에는 적용하지 않는다. timeout 상한에 붙은
지연과 포화 실행은 단순 변화율로 해석하지 않는다.

## 변경 절차

임계값을 바꿀 때는 반복 실행에서 관측한 노이즈, 사용자 목표 또는 자원 한계를 근거로 남긴다.
코드 변경의 결과를 본 뒤 그 실행만 통과하도록 규칙을 조정하지 않는다.
