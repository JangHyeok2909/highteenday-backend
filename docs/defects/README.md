# defects — 결함 상세 기록

[KNOWN-ISSUES.md](../KNOWN-ISSUES.md)의 항목 중 **본문 몇 줄로 설명되지 않는 것**의 상세
기록을 둔다. 원인 분석, 실측 근거, 해결 후보 비교가 필요한 결함이 대상이다.

## 규칙

- **KNOWN-ISSUES가 단일 출처다.** 모든 결함은 먼저 `KI-nn` 항목으로 등록된다.
  이 디렉터리의 문서는 그 항목의 부록이지 별도 목록이 아니다.
- 파일명은 `KI-nn-짧은-설명.md`. **별도 번호 체계를 만들지 않는다** — `DEF-nn` 같은
  두 번째 ID가 생기면 같은 결함이 두 이름으로 불리게 된다.
- KI 항목에서 이 문서로 링크하고, 이 문서 머리에서 KI로 되돌아가는 링크를 단다.

## 여기 없는 것

| 종류 | 어디에 |
|---|---|
| 성능 병목 | [`performance/bottlenecks/`](../../performance/bottlenecks/) — 느려서 문제인 것 |
| 측정 시스템의 결함 | `localDocs/findings/perf-findings-*.md` — 성능 테스트 도구·부하 스크립트·환경 |

이 디렉터리는 **애플리케이션이 틀린 경우**만 다룬다. 서버를 빠르게 만들어도 사라지지 않고,
부하를 걸지 않아도 존재하는 결함이다.
